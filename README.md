# ECAI 2025
The following branch includes the PEML implementations mentioned in the submission for the "Machine Learning Meets Differential Equations 2025 Workshop"

## Prerequisites:
- Python 3.10
- Ubuntu 20.04 LTS

```bash
pip install -r requirements.txt
```

## Instructions

For tuning our models:
```bash
chmod +x tune.sh
./tune.sh
```

For running our comparison pipeline:
```bash
chmod +x compare.sh
./compare.sh
```
